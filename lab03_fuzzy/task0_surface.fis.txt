FIS (текстовий експорт): first

Апроксимація поверхні y = (x1^2 - 8)*cos(x2) на x1,x2 in [0,4].
Відтворює СНВ з кроків 2-17 методички (у MATLAB система
називається first.fis). Параметри ФН згенеровані за тим самим
правилом, що й у Fuzzy Logic Designer при Edit -> Add MFs...

[System]
Name        = first
Type        = mamdani
NumInputs   = 2
NumOutputs  = 1
NumRules    = 9
AndMethod   = min
OrMethod    = max
ImpMethod   = min
AggMethod   = max
DefuzzMethod= centroid

[Input1]
Name  = x1
Range = [0.0 4.0]
NumMFs= 3
# 3 трикутні терми: L (низький), A (середній), H (високий)
MF1 = 'L':'trimf',[-2 0 2]
MF2 = 'A':'trimf',[0 2 4]
MF3 = 'H':'trimf',[2 4 6]

[Input2]
Name  = x2
Range = [0.0 4.0]
NumMFs= 5
# 5 гаусових термів; sigma підібрана так, щоб сусідні ФН перетиналися на рівні 0.5
MF1 = 'L':'gaussmf',[0.424661 0]
MF2 = 'LA':'gaussmf',[0.424661 1]
MF3 = 'A':'gaussmf',[0.424661 2]
MF4 = 'HA':'gaussmf',[0.424661 3]
MF5 = 'H':'gaussmf',[0.424661 4]

[Output1]
Name  = y
Range = [-10.0 10.0]
NumMFs= 5
# 5 трикутних термів L/LA/A/HA/H
MF1 = 'L':'trimf',[-15 -10 -5]
MF2 = 'LA':'trimf',[-10 -5 0]
MF3 = 'A':'trimf',[-5 0 5]
MF4 = 'HA':'trimf',[0 5 10]
MF5 = 'H':'trimf',[5 10 15]

[Rules]
# формат: антецедент => консеквент (вага)
 1. x1=L  and x2=L  => y=L   (1)
 2. x1=L  and x2=H  => y=A   (1)
 3. x1=L  and x2=HA => y=H   (1)
 4. x1=H  and x2=L  => y=HA  (1)
 5. x1=H  and x2=H  => y=L   (1)
 6. x1=A  and x2=A  => y=A   (1)
 7. x1=A  and x2=HA => y=HA  (1)
 8. x1=L  and x2=LA => y=LA  (1)
 9. x1=A  and x2=HA => y=A   (1)   # той самий антецедент, що й у правилі 7

[Notes]
- Методичка пише «сформуємо наступні десять правил», але перелічує 9; підпис до рис. 5 теж говорить про «усі 9 правил».
- Правила 7 і 9 мають однаковий антецедент (x1=A and x2=HA) та різні консеквенти (HA і A) — у Мамдані це дає усереднений результат.
- База правил покриває лише 8 із 15 можливих комбінацій термів, тому поверхня СНВ лише грубо повторює форму точної функції.
