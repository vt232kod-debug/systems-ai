==============================================================================
FIS (текстовий експорт): air_conditioner
==============================================================================
Нечітке керування кондиціонером приміщення. Другий вхід —
швидкість зміни температури (може бути від'ємною), що враховує
теплову інертність процесу нагріву/охолодження.
Кут регулятора: вліво («−») = «холод», вправо («+») = «тепло».

[System]
Name        = air_conditioner
Type        = mamdani
NumInputs   = 2
NumOutputs  = 1
NumRules    = 15
AndMethod   = min
OrMethod    = max
ImpMethod   = min
AggMethod   = max
DefuzzMethod= centroid

[Input1]
Name  = t
Range = [10.0 34.0]
NumMFs= 5
# температура повітря, °C; комфорт 22 °C; терми: VC=дуже холодна, C=холодна, N=в нормі, W=тепла, VW=дуже тепла
MF1 = 'VC':'gaussmf',[2.54797 10]   # дуже холодна
MF2 = 'C':'gaussmf',[2.54797 16]   # холодна
MF3 = 'N':'gaussmf',[2.54797 22]   # в нормі
MF4 = 'W':'gaussmf',[2.54797 28]   # тепла
MF5 = 'VW':'gaussmf',[2.54797 34]   # дуже тепла

[Input2]
Name  = dt
Range = [-1.0 1.0]
NumMFs= 3
# швидкість зміни температури, °C/хв; терми: NEG=від'ємна (температура падає), ZERO=нуль (температура стабільна), POS=додатня (температура зростає)
MF1 = 'NEG':'trimf',[-2 -1 0]   # від'ємна (температура падає)
MF2 = 'ZERO':'trimf',[-1 0 1]   # нуль (температура стабільна)
MF3 = 'POS':'trimf',[0 1 2]   # додатня (температура зростає)

[Output1]
Name  = angle
Range = [-90.0 90.0]
NumMFs= 5
# кут повороту регулятора кондиціонера, град
MF1 = 'BL':'trimf',[-135 -90 -45]   # великий кут вліво — «холод» на максимум
MF2 = 'SL':'trimf',[-90 -45 0]   # невеликий кут вліво — «холод» помірно
MF3 = 'OFF':'trimf',[-45 0 45]   # кондиціонер вимкнено
MF4 = 'SR':'trimf',[0 45 90]   # невеликий кут вправо — «тепло» помірно
MF5 = 'BR':'trimf',[45 90 135]   # великий кут вправо — «тепло» на максимум

[Rules]
# формат: антецедент => консеквент (вага)
 1. t=VW and dt=POS  => angle=BL   (1)
 2. t=VW and dt=NEG  => angle=SL   (1)
 3. t=W  and dt=POS  => angle=BL   (1)
 4. t=W  and dt=NEG  => angle=OFF  (1)   # правило 4 у методичці обірване
 5. t=VC and dt=NEG  => angle=BR   (1)
 6. t=VC and dt=POS  => angle=SR   (1)
 7. t=C  and dt=NEG  => angle=BR   (1)   # ВИПРАВЛЕНО: у методичці «вліво»
 8. t=C  and dt=POS  => angle=OFF  (1)
 9. t=VW and dt=ZERO => angle=BL   (1)
10. t=W  and dt=ZERO => angle=SL   (1)
11. t=VC and dt=ZERO => angle=BR   (1)
12. t=C  and dt=ZERO => angle=SR   (1)
13. t=N  and dt=POS  => angle=SL   (1)
14. t=N  and dt=NEG  => angle=SR   (1)
15. t=N  and dt=ZERO => angle=OFF  (1)

[Notes]
- Правило 7 методички суперечливе: сказано увімкнути режим «тепло», але повернути регулятор «на великий кут вліво», хоч вліво = «холод». Реалізовано виправлено: angle=BR (великий кут вправо).
- Правило 4 методички обірване: «...включити режим «холод», повернувши регулятор кондиціонеру слід вимкнути». Трактуємо як angle=OFF: температура тепла, але вже падає сама — охолоджувати не потрібно.
- База правил покриває всі 15 комбінацій 5 термів температури на 3 терми похідної, тому розріджених зон у поверхні виводу немає.
